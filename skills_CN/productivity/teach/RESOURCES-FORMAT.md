# RESOURCES.md 格式

`RESOURCES.md` 是本主题的精选可信来源集合。讲解中的知识应从这里提取，而不是参数化的猜测。智慧来自这里列出的社区。

## 结构

```md
# {主题} 资源

## 知识

- [书籍：_力量训练的科学与实践_ — Zatsiorsky & Kraemer](https://example.com)
  编程与适应的基础文本。用途：任何与周期化、恢复、强度区间相关的内容。
- [文章："我应该练多少？" — Greg Nuckols（Stronger By Science）](https://example.com)
  基于证据的训练量基准综述。用途：每个肌群的每周组数目标。

## 智慧（社区）

- [r/weightroom](https://reddit.com/r/weightroom)
  高信噪比 subreddit，对伪科学有适度审核。用途：计划批评、平台期突破。
- 本地：周二力量课 at {健身房名称}
  用途：举重动作的实时教练反馈。
```

## 规则

- **仅高可信度。** 优先选择一手资料、公认专家、同行评审作品和有强力审核的社区。如果某个资源是披着教育外衣的营销内容，排除它。
- **每个条目都要有注解。** 一个裸链接在三个月后毫无用处。加一行：它涵盖什么，什么时候该用它。
- **按 知识 / 智慧 分组。** 对应 [SKILL.md](./SKILL.md) 中的哲学。一个资源可以只出现在一个分组中。
- **显式指出空白。** 如果某个任务需要的领域没有好的资源，写一个 `## 空白` 部分列出缺失的内容。这驱动未来的搜索。
- **无情修剪。** 事实证明有误、肤浅或偏离任务的资源应该删除，而不是埋没。五个精准来源胜过三十个平庸来源。
- **记录社区偏好。** 如果用户选择不加入社区，在这里注明，这样未来的会话不会反复提议。
