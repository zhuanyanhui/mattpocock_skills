# GLOSSARY.md 格式

`GLOSSARY.md` 是本教学工作空间的规范语言。所有讲解、练习和学习记录都应遵循其术语。构建它本身就是学习的一部分：将一个概念压缩为简洁的定义，就是用户理解它的证据。

## 结构

```md
# {主题} 词汇表

{一两句话描述本词汇表涵盖的主题。}

## 术语

**增肌（Hypertrophy）**：
通过重复训练中的机械张力和代谢压力驱动的肌肉增长。
_避免使用_：堆肌肉、变大

**渐进超负荷（Progressive overload）**：
随时间系统性地增加肌肉的负荷——通过重量、容量或强度。
_避免使用_：加大力度、升级

**RPE（主观疲劳度，Rate of Perceived Exertion）**：
一个 1-10 的自我评分，评估一组训练的吃力程度，10 为力竭，8 表示还能做两次。
_避免使用_：努力分数、强度等级
```

## 规则

- **仅在用户理解后才添加术语。** 词汇表是压缩知识的记录，不是用户用来学习的字典。如果用户刚接触一个概念，等到他们能正确使用后再收录。
- **要有倾向性。** 当同一个概念存在多个词时，选择最佳的一个，将其他列为需要避免的别名。这就是语言的压缩方式。
- **保持定义简洁。** 一到两句话。定义术语**是什么**，而不是它做什么或怎么做。
- **在定义中使用词汇表自身的术语。** 一旦术语收录到词汇表中，在所有地方（包括其他定义中）都应优先使用它。这使得复杂术语更容易被后续理解。
- **当自然聚类出现时分组到子标题下**（例如 `## 解剖学`、`## 编程`）。当术语内聚时，平铺列表也可以。
- **显式标记歧义。** 如果一个术语在更广泛的领域中使用模糊，说明解决方案："在本工作空间中，'组'始终指工作组——热身组单独跟踪。"
- **随着理解的深入修订。** 用户第一周写的定义到第六周可能已经不对了。就地更新，不要保留过时的条目。
