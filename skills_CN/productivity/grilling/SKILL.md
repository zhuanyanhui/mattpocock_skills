---
name: grilling
description: 就计划、决策或想法无情地追问用户。当用户想要压力测试他们的思考，或使用任何"grill"触发短语时使用。
---

无情地追问用户，直到你们达成共同理解。将其映射为一棵**决策树**：每个决策都会分支出挂在它上面的其他决策。

以**轮次**推进决策树。**前沿**（frontier）是所有前置条件已经确定的决策——也就是你*现在*就能问的问题，无需猜测尚未听到的答案。在一轮中问完整的前沿：给每个问题编号并给出你的推荐答案。然后等待用户的回答，再进入下一轮。

每个问题应按以下格式呈现：

```
❓ **Q1** - **<问题标题>**：<问题正文，可能是多段，包含多个选项>

➡️ <你的推荐答案>
```

用户的每轮回答都会重塑决策树——已确定的决策将前沿向外推进，解锁依赖它们的问题。重新计算前沿并提出下一轮问题。如果某个问题的答案依赖于本轮中尚未开放的另一问题，它属于*后续*轮次，而非本轮。

查找*事实*是你的工作，绝不是用户的。当前沿问题需要环境（文件系统、工具等）中的事实时，派一个子 agent 去查找——不要问任何你可以自己查到的东西。不要因此阻塞整轮：一个运行中的探索是未解决的前置条件，所以只有依赖于它的下游问题需要等待子 agent 报告——现在去问前沿的其他问题。*决策*是用户的——把每个决策都提出来并等待。

当前沿为空时，会话就结束了：决策树的每个分支都已访问，没有任何内容被默默假设。在用户确认你们已达成共同理解之前，不要对其采取行动。
