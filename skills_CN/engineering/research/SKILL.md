---
name: research
description: 基于高可信度的一手资料调查问题，并将发现结果保存为仓库中的 Markdown 文件。当用户想要研究某个主题、收集文档或 API 事实、或将阅读工作委托给后台代理时使用。
---

启动一个**后台代理**来进行研究，这样你可以在它阅读的同时继续工作。

它的任务：

1. 基于**一手资料**（primary sources）调查问题——官方文档、源代码、规范、第一方 API——而不是基于这些资料的二手转述。将每个主张追溯到拥有它的源头。
2. 将发现结果写入单个 Markdown 文件，并引用每个主张的来源。
3. 将其保存在仓库中已有的存放此类笔记的位置；遵循现有约定，如果没有约定，则放在一个合理的位置并说明位置。
