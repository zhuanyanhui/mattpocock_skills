---
name: resolving-merge-conflicts
description: "当需要解决进行中的 git 合并/变基冲突时使用。"
---

1. **查看当前状态**——检查合并/变基的状态、git 历史和冲突文件。

2. **找到每个冲突的一手资料**。深入了解每个更改的原因以及原始意图。阅读提交信息、查看 PR、检查原始 issue/ticket。

3. **解决每个 hunk（变更块）。** 尽可能保留双方的意图。在不兼容的情况下，选择符合合并目标的一方，并记下权衡。**不要**发明新的行为。始终解决；永远不要 `--abort`。

4. 发现项目的**自动化检查**并运行它们——通常是类型检查，然后是测试，最后是格式化。修复合并导致的任何问题。

5. **完成合并/变基。** 暂存所有内容并提交。如果是变基，继续变基过程直到所有提交完成变基。
